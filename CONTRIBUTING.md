# Contributing to SkinFutures

Thank you for your interest in contributing! 🎉

## Development Setup

```bash
git clone https://github.com/gabbyy042/SkinFutures.git
cd SkinFutures
npm install
cp .env.local.example .env.local
# Edit .env.local with your Firebase credentials
npm run dev
```

## Code Style

- Use TypeScript for all new files
- Follow existing code patterns
- Use Tailwind CSS for styling
- Keep components small and focused
- Add comments for complex logic

## Pull Request Process

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Commit changes (`git commit -m 'Add amazing feature'`)
4. Push to branch (`git push origin feature/amazing-feature`)
5. Open a Pull Request

## Guidelines

### Important Rules

- **NO medical claims** - This is a motivation app, not medical software
- **Privacy first** - Handle user data securely
- **No fear tactics** - Keep messaging positive and encouraging
- **Mobile-first** - Test on mobile devices
- **Keep it simple** - MVP focuses on core features

### What to Contribute

**High Priority:**
- Bug fixes
- Performance improvements
- Accessibility enhancements
- Mobile UI improvements
- Documentation updates

**Medium Priority:**
- New skincare routine templates
- Additional lifestyle factors
- UI/UX refinements
- Animation improvements

**Out of Scope (for now):**
- Medical diagnosis features
- 3D avatars
- AR features
- Complex ML models
- Social features

## Testing

Before submitting:
1. Test all user flows
2. Check mobile responsiveness
3. Verify disclaimers are visible
4. Test with different browsers
5. Check Firebase integration

## Questions?

Open an issue or reach out via GitHub Discussions!
